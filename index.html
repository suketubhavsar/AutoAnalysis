How to update vehicle data

  • Efficiency: the Refresh efficiency (EPA) button works directly from the browser (fueleconomy.gov allows it).
  • Prices / configurations: manufacturer sites block browser requests (CORS) and render prices with JavaScript. Run powershell -ExecutionPolicy Bypass -File ..\Update-Vehicles.ps1, then reload this page - a banner will offer the new data. Anything the script can't read is left unchanged and flagged "unverified".
  • Or edit any vehicle by hand (click its name); edits are saved in your browser.
